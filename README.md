# Nube DJ 0.3.0

Android two-deck DJ prototype focused on cloud music and a more physical DJ workflow.

Current build includes large touch waveforms, vertical pitch faders, jog scrub/nudge, momentary CUE, loops, SYNC, crossfader, VU meters, EQ/channel mixer, automatic BPM analysis, analysis cache, local files and Google Drive library/streaming.

Package: `cl.fernando.nubedj`

The debug APK is produced by `.github/workflows/android-debug.yml` as `Nube-DJ-v0.3.0-debug`.
