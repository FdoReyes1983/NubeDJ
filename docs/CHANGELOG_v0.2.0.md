# Nube DJ v0.2.0 — cambios

- Rediseño completo de la pantalla de mezcla en horizontal.
- Waveform en movimiento por deck con playhead central.
- Análisis automático de BPM y amplitud usando MediaExtractor/MediaCodec en segundo plano.
- Jog wheel visual por deck.
- Mixer con VU meters, crossfader equal-power y EQ LOW/MID/HIGH por deck.
- Google Drive integrado: autorización read-only, Mi Drive, Compartidos, carpetas, búsqueda, LOAD A y LOAD B.
- Caché privada de canciones de Drive para permitir reproducción, búsqueda y análisis local.
- Estados dentro de cada deck; se eliminan avisos emergentes rutinarios de CUE/SET/SYNC.
- GitHub Actions actualizado a android-actions/setup-android@v4.
- versionCode 2 / versionName 0.2.0.
