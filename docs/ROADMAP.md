# Nube DJ Roadmap

## v0.3.x
- Tune layout on real phones and tablets.
- Improve waveform cache/progressive analysis.
- Beat grid and phase indicator.
- Hot cues.

## v0.4
- Native low-latency audio engine using Oboe/AAudio.
- Real vinyl scratch with bidirectional audio.
- Headphone cue routing where supported.
- Quantized loops and tighter sync.

## Later
- FX rack, sampler, recording, key detection/key lock, MIDI controllers, AutoMix.
